# OBP frame relay

Ticket-gated **hub relay** for OBP negotiation byte streams: stamp optional `RelayEnvelope`, fan out opaque frames, and spool them for late joiners.

## Layout

| Path | Package |
|------|---------|
| `spec/model/` | `@khoralabs/obp-frame-relay-spec` — `RelayEnvelope` wire policy + `FrameRelayStore` persistence service |
| `impl/ts/` | `@khoralabs/obp-frame-relay` — hub runtime, store strategy port, in-memory adapter, Bun WS helpers |
| `sqlite/` | `@khoralabs/obp-frame-relay-sqlite` — reference SQLite `FrameRelayStoreStrategy` |

## TypeScript

```bash
cd packages/frame-relay/impl/ts && bun test && bun run typecheck
cd packages/frame-relay/sqlite && bun test && bun run typecheck
```

## Admission tickets

Channel join proofs are HMAC-SHA256 tickets generated by the hub at channel creation time. The ticket utilities live in `@khoralabs/duplex-byte-stream` (`generateChannelSecretHex`, `signChannelTicket`, `verifyChannelTicket`). Product adapters responsible for delivering channel tickets to peers live outside this package.
